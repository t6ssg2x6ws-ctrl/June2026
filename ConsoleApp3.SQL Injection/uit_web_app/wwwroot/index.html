C# SQL Injection Security Analysis

Directly derived from dapperservice.cs, parameterized queries with Dapper in C# isolate parameter values from SQL logic.

Vulnerable C# String Interpolation 
// UNSAFE (dapperservice.cs L27):
$"select * from [dbo].[users] where username='{nae}' and password_hash='{psw}';"

Risk: Concatenating raw user inputs enables attacker input strings to alter query grammar.

Safe C# Dapper Parameterization 
// SAFE (dapperservice.cs L29-30):
"select * from [dbo].[users] where username=@username and password_hash=@password_hash",
new { username = nae, password_hash = psw }

Protection: SqlClient escapes values and sends parameters out-of-band via sp_executesql.
